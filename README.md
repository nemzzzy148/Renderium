# Renderium

`Renderium` is cross-platform, modern graphics API that can translate your gpu instructions to the optimal underlying graphics API.

## General info

### !!!This project is currently in development!!!

`Renderium` is extremely similar to the WebGPU standard making it effortless for WebGPU users or for people beginning with graphics.

> ### Supported backend graphics API
> * Vulkan

## Updates?

Right now, this project is a work in progress that will later work in hand with `Obsidium` to act as the graphical backend.
